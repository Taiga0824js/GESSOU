# GESSOU

和風・高難易度・5連戦型ターン制RPGの初期プロトタイプ。

## 現在入っているもの
- 月相が戦闘中ずっと進行
- キャラ個別の「奏力」(Mana)
- 毎ターンの奏力自然回復（新月で増加、満月で減少）
- 通常攻撃で奏力回復
- BREAKゲージ
- 1行動=1拍 / 4拍=1小節
- 小節完成時にパーティの奏力を回復
- ダメージに95〜105%の乱数
- 侍 / 仙人 / 傘使い / 巫女 / 提灯使い / 呪詛師 の基礎データ
- 静止画素材なしでも成立する和風UIと簡易斬撃演出

## 起動
Godot 4.x で `project.godot` を開き、F6/F5 で実行。

## 画像を入れる場所
- `assets/icons/`

## 音を入れる場所
- `assets/audio/`

短い楽器音は WAV/OGG 推奨。
