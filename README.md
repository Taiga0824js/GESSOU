# 月奏 / GESSOU

![Build GESSOU](https://github.com/Taiga0824js/GESSOU/actions/workflows/build.yml/badge.svg)

**月相・奏譜・崩しを読みながら、3人の行動を組み立てる和風高難易度ターン制RPG。**

探索や街はなく、戦闘そのものに特化した作品です。  
10人のキャラクターから3人を選び、5連戦のボス戦を攻略します。

---

## 現在のゲーム内容

### 3人を選ぶパーティ編成

現在のプレイアブルキャラクターは10人。

- 侍
- 仙人
- 傘使い
- 巫女
- 提灯使い
- 呪詛師
- くノ一
- 酒呑童子
- 神楽師
- 猫又

それぞれ役割・速度・耐久・崩し性能・奏譜への関わり方が異なります。

各キャラクターは通常行動に加えて、**5つの固有特技**と**1つの固有必殺技**を持ちます。

---

## 戦闘システム

### 行動順

戦闘はCTB形式の行動順を使用します。

1巡の開始時に、行動順が早い味方から3人分の行動を先に選択します。

```text
くノ一 → 敵 → 巫女 → 猫又 → …
```

この場合、入力順は

```text
1. くノ一
2. 巫女
3. 猫又
```

となり、3人分を決めたあと、敵を含めて実際の行動順で戦闘が進みます。

技ごとに待ち時間が異なり、次に戻ってくる位置も変わります。

---

## 月相

月は1人が動くたびには変化しません。

**1巡の開始時に月相が確定し、その巡が終わるまで同じ効果が続きます。**

```text
新月
↓
三日月
↓
上弦
↓
十三夜
↓
満月
↓
十六夜
↓
下弦
↓
晦
```

通常は1巡ごとに1相進みます。

月操作を持つ技によって、次巡の月相をさらに進めることもできます。

### 月相の主な特徴

| 月相 | 主な特徴 |
|---|---|
| 新月 | 奏力回復・立て直し |
| 三日月 | 速度・通常攻撃の奏力回収 |
| 上弦 | 崩し性能 |
| 十三夜 | 与ダメージ |
| 満月 | 高火力・敵も強化 |
| 十六夜 | 毒・火傷・状態異常 |
| 下弦 | 回復・防御 |
| 晦 | 弱体中の敵への追撃 |

戦闘中の **月相表** から、各月の効果と共鳴音紋を確認できます。

---

## 奏譜

GESSOUの中心システムのひとつ。

**1行動 = 1拍、8拍 = 1奏譜**。

行動にはそれぞれ音紋があり、8拍の並びによって奏譜が成立します。

現在の基本奏譜：

- 昇奏
- 降奏
- 重奏
- 濁奏
- 返奏
- 静奏
- 彩奏
- 合奏
- 余韻

月相と音紋が強く共鳴した場合は、さらに **月奏** へ昇格します。

例：

- 朔月・静奏
- 三日月・疾奏
- 上弦・破奏
- 十三夜・調奏
- 望月・烈奏
- 十六夜・妖奏
- 下弦・守奏
- 晦・葬奏

奏譜完成時には、奏譜名だけでなく**発動効果も画面上に表示**されます。

戦闘中の **奏譜指南** から成立条件と効果を確認できます。

---

## 固有必殺技

必殺技はゲージを溜めるだけでは使用できません。

**キャラクターごとに指定された奏譜を完成させることで解放**されます。

| キャラクター | 解放条件 | 必殺技 |
|---|---|---|
| 侍 | 上弦・破奏 | 天月一閃 |
| 仙人 | 朔月・静奏 | 九天月輪 |
| 傘使い | 下弦・守奏 | 八重時雨 |
| 巫女 | 十三夜・調奏 | 天照神楽 |
| 提灯使い | 望月・烈奏 | 百鬼灯明 |
| 呪詛師 | 十六夜・妖奏 | 百怨月葬 |
| くノ一 | 三日月・疾奏 | 月影千刃 |
| 酒呑童子 | 濁奏 | 鬼宴・月呑 |
| 神楽師 | 合奏 | 八百万神楽 |
| 猫又 | 晦・葬奏 | 双月猫又火 |

使用すると再び封印され、同じ奏譜を完成させることで再解放できます。

## 崩し / BREAK

敵と味方の両方に「構え」があります。

構えを削り切ると崩壊状態になり、

- 行動キャンセル
- 大技準備の解除
- 行動不能
- 被ダメージ増加

などが発生します。

同じ技だけを繰り返すと効率が落ちる仕組みもあり、通常攻撃・防御・奏譜・月相を組み合わせることが重要です。

---

## ボス戦

現在は5連戦構成。

各ボスは同じ行動パターンではなく、それぞれ異なる戦い方を要求します。

- 第1夜：崩し
- 第2夜：火傷管理
- 第3夜：奏譜妨害
- 第4夜：行動順操作
- 第5夜：月相操作

さらにHPが減ると**第二相**へ移行し、行動やギミックが変化します。

大技は事前に予兆が表示され、崩し・防御・月相・行動順操作などで対処できます。
