# GESSOU / 月奏

和風ダークファンタジーの戦闘専用RPG。3人を編成し、CTB・月相・BREAK・8拍の奏譜を組み合わせて五夜のボスへ挑む。

## v0.11.0
- 13人から3人を編成。
- 78特技 + 13必殺技。
- キャラクター詳細画面を追加。
- 雪女 / 墓守 / 陰陽師を追加。
- 月相にメリットだけでなく危険も追加。
- 第四夜「常闇天狗」の火力を調整。
- 奏譜は8拍。防御では音を置かず、拍を保持したまま月を待てる。
- 複数の奏譜役を同時成立可能。奏価が加算され、対応する指定奏譜でのみ必殺技が解放される。
- 敵大技の準備中はボス横に常駐予兆FXを表示。

## 主要システム
- 3人分の行動を先に選択してからCTB順に解決。
- 8つの月相は一巡中固定。
- 月相には「恵」と「禍」があり、欲しい月を待つこと自体にリスクがある。
- 奏譜完成時は役を後段で加算表示し、奏価・奏格を演出。
- BREAKで敵の大技を中断可能。
- ボス5体 + 第二形態。
